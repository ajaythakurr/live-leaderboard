Live Leaderboard System

A high-performance real-time leaderboard application that enables instant score tracking and ranking updates using Redis Sorted Sets. Built with the MERN stack, containerized with Docker, and documented using Swagger/OpenAPI, this project demonstrates scalable backend design for gaming, competitions, and analytics platforms.

Features
🚀 Real-time leaderboard updates
⚡ Redis Sorted Sets for fast ranking operations
📊 Top N players retrieval
🔍 Player rank lookup
➕ Score increment and update APIs
📄 Swagger/OpenAPI documentation
🐳 Dockerized development environment
🗄️ MongoDB for persistent player data
🔒 RESTful API architecture
📈 Scalable system design
Tech Stack
Frontend: React
Backend: Node.js + Express.js
Database: MongoDB
Cache & Ranking Engine: Redis
API Documentation: Swagger/OpenAPI
Containerization: Docker & Docker Compose

This project is designed to demonstrate how Redis can be used to build low-latency, real-time ranking systems similar to those used in gaming platforms, coding contests, fantasy sports applications, and live analytics dashboards.
